* AI Skills

A collection of [[https://opencode.ai/docs/skills][opencode skill]] definitions encoding
recurring project conventions and workflows.

The skill files are plain [[https://agentskills.io][SKILL.md]] documents, so any harness that
speaks that format can load them.

For global discovery:

| Harness     | Location                                          |
|-------------+---------------------------------------------------|
| opencode    | =~/.agents/skills/= or =~/.config/opencode/skills/= |
| Claude Code | =~/.claude/skills/<name>/SKILL.md=                  |

Symlink =skills/= to the directory when the checkout is permanent;
copy it when the checkout is not (Claude Code follows symlinks, but
a link into a temporary mount breaks silently when the mount goes).

All skills are licensed under MIT — see =LICENSE=.

** Available skills

| Name                   | Description                                      |
|------------------------+--------------------------------------------------|
| python-dev             | Python conventions: setuptools, ruff, pytest, uv |
| git-conventions        | Git workflow: two-branch, conventional commits   |
| create-skill           | Guide for generating new opencode skills         |
| latex-paper-revision   | LaTeX paper revision and enhancement workflow    |
| ml-project             | Research ML project conventions (DVC, MLflow, HPO) |
| auto-hpo-studies       | Autonomous HPO loop: define target, iterate update-config run monitor commit until convergence. Uses MLflow, sleep-based polling |
| paper-writing          | End-to-end paper writing workflow: figure generation, LaTeX templates (IEEE/Elsevier/UAI), revision cycles, venue submission |
