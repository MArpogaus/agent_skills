* AI Skills

A collection of agent skill definitions for [[https://claude.com/claude-code][Claude Code]] and
[[https://opencode.ai/docs/skills][opencode]]. They encode recurring project conventions
and workflows.

The skill files are plain [[https://agentskills.io][SKILL.md]] documents, so any harness that
speaks that format can load them.

** Installation

Clone to =~/.agents/=, which opencode reads natively:

#+begin_src bash :exports code
  git clone git@github.com:MArpogaus/agent_skills.git ~/.agents
#+end_src

=~/.agents/skills/= is then the single source of truth. Claude Code
reads the same checkout *in place*. There is no copy, no symlink and
nothing to keep in sync. Register it with Claude Code:

#+begin_src bash :exports code
  claude plugin marketplace add ~/.agents
  claude plugin install marpogaus-skills@marpogaus-skills
#+end_src

Or install straight from GitHub on a machine without the checkout:

#+begin_src bash :exports code
  claude plugin marketplace add MArpogaus/agent_skills
  claude plugin install marpogaus-skills@marpogaus-skills
#+end_src

Inspect what a session pays for them with
=claude plugin details marpogaus-skills@marpogaus-skills=.
