#+title: Optional header additions
#+startup: show2levels

Nothing here belongs in a default header. Add a stanza only when a
frame needs it. Use `#+BEAMER_HEADER:` for beamer-only settings.

* Numbers from a data file
Reads a value from a JSON file in the sidecar. Write
`{{{num(model.auc)}}}` in the text, or `{{{num(cohort.n,%d)}}}` for a
different format. Keys are dot-separated.

#+begin_src org
,#+macro: num (eval (let ((v (with-temp-buffer (insert-file-contents "<sidecar>/numbers.json") (json-parse-buffer)))) (dolist (k (split-string $1 "\\.")) (setq v (gethash k v))) (format (or (org-string-nw-p $2) "%.3f") v)))
#+end_src

* Section TOC frames
For talks longer than 15 minutes, for example a conference talk.

#+begin_src org
,#+BEAMER_HEADER: \AtBeginSection[]{\begin{frame}<beamer>\tableofcontents[currentsection]\end{frame}}
#+end_src

* Institute line or logos on the title slide
A plain line, or logos with `\inst{n}` markers on the authors in
`#+AUTHOR:`. Logos live in the sidecar folder.

#+begin_src org
,#+BEAMER_HEADER: \institute{<Affiliation>}
,#+BEAMER_HEADER: \institute[<Short>]{\inst{1}\includegraphics[height=2.5em]{<logo1>.pdf}\hfill\inst{2}\includegraphics[height=2.5em]{<logo2>.pdf}}
#+end_src

* TikZ diagrams
Only for frames with an inline `tikzpicture`. Load the libraries that the
picture uses. Use theme colours (`mLightBrown`, `mDarkTeal`) for fills.

#+begin_src org
,#+BEAMER_HEADER: \usepackage{tikz}
,#+BEAMER_HEADER: \usetikzlibrary{positioning, arrows.meta}
#+end_src

* Occasional packages
One line each, added when a frame uses it:

| Package | Add when |
|---------+---------------------------------------------|
| `subcaption` | a figure has sub-panels with own captions |
| `multirow` | a table spans a cell over several rows |
| `booktabs` | a table is exported with `:booktabs t` |
| `xfrac` | inline slanted fractions, `\sfrac{1}{3}` |

* Link colours
`mLightBrown` exists only under metropolis.

#+begin_src org
,#+BEAMER_HEADER: \hypersetup{colorlinks, linkcolor=, urlcolor=mLightBrown}
#+end_src

* Frame number in the footer
For themes without a frame counter (Szeged, SimplePlus).

#+begin_src org
,#+BEAMER_HEADER: \addtobeamertemplate{navigation symbols}{}{%
,#+BEAMER_HEADER:   \usebeamerfont{footline}\usebeamercolor[fg]{footline}%
,#+BEAMER_HEADER:   \hspace{1em}\raisebox{1.4pt}[0pt][0pt]{\insertframenumber / \inserttotalframenumber}}
#+end_src

* Code frames
Only for a specialist audience. Stops evaluation on export.

#+begin_src org
,#+PROPERTY: header-args :results silent :eval never-export
,#+LATEX_HEADER: \usepackage{listings}
,#+LATEX_HEADER: \lstset{showstringspaces=false,breaklines=true,basicstyle=\small, keywordstyle=\color{mLightBrown},stringstyle=\color{mLightBrown},numberstyle=\color{mLightBrown},commentstyle=\color{lightgray}}
#+end_src

The =\lstset= colours are metropolis names. Pin the backend at the end
of the file:

#+begin_src org
,# Local Variables:
,# org-latex-listings: listings
,# End:
#+end_src

* Local package on TEXINPUTS
A `.sty` outside the TeX tree must be on `TEXINPUTS` at export time.

#+begin_src org
,#+BEAMER_HEADER: \usepackage[<options>]{<package>}

# Local Variables:
# eval: (setenv "TEXINPUTS" ".:<path/to/tex/sty>:")
# End:
#+end_src
