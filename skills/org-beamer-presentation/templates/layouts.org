#+title: Frame layouts for org-beamer presentations
#+startup: show2levels

Copy a layout under a =**= frame heading and fill it. Levels assume
=H:2=: =*= section, =**= frame, =***= column or block. The hard rules
of SKILL.md apply to every layout.

* Figure frame (the default)
One figure and at most two short lines. Plain lines need no bullets
when there is only one.

#+begin_src org
,#+ATTR_LATEX: :width \linewidth :height 0.7\textheight :options keepaspectratio
[[file:<figure>.pdf]]

- <line of at most 12 words> [cite:@Key]
- <line of at most 12 words>
#+end_src

* Figure beside text
Figure left, text right. Org wraps consecutive =:BMCOL:= siblings in
=columns=.

#+begin_src org
,*** Figure :BMCOL:
:PROPERTIES:
:BEAMER_col: 0.55
:END:
,#+ATTR_LATEX: :width \linewidth :height 0.7\textheight :options keepaspectratio
[[file:<figure>.pdf]]

,*** Text :BMCOL:
:PROPERTIES:
:BEAMER_col: 0.45
:END:
- <point>
- <point>
#+end_src

* Two contrasting examples
Two figures at one shared scale, for example two graphs. Never more than
two.

#+begin_src org
,*** A :BMCOL:
:PROPERTIES:
:BEAMER_col: 0.5
:END:
,#+ATTR_LATEX: :width \linewidth :height 0.7\textheight :options keepaspectratio
[[file:<example-a>.pdf]]

,*** B :BMCOL:
:PROPERTIES:
:BEAMER_col: 0.5
:END:
,#+ATTR_LATEX: :width \linewidth :height 0.7\textheight :options keepaspectratio
[[file:<example-b>.pdf]]
#+end_src

* Text frame
At most three bullets, each at most two lines at full width. A block
title above a list is allowed, as in the user's decks.

#+begin_src org
,*** <Block title> :B_block:
- <point>
- <point>
- <point>
#+end_src

* Entity grid
For items that share the same fields: one block per item, lines
joined with =\\=.

#+begin_src org
,*** [[<url>][<Name>]] (<place>) :B_block:
,*Idea:* <one line> \\
,*Status:* <one line>
#+end_src

* Display math
Only for a specialist audience. Always a raw export block.

#+begin_src org
,#+begin_export latex
\begin{equation*}
  \hat{\theta} = \arg\min_\theta L(\theta)
\end{equation*}
,#+end_export
#+end_src

* Table
Few columns, few words. For =p{}= widths see =reference/pitfalls.md=.

#+begin_src org
,#+ATTR_LATEX: :align llr
| Dataset | Model | Accuracy  |
|---------+-------+-----------|
| <A>     | <M1>  | $0.0 \pm 0.0$ |
#+end_src

* Code frame
Only for a specialist audience. Needs the code stanza from
=header-extras.org=. ox-beamer marks the frame fragile by itself.

#+begin_src org
,#+ATTR_LATEX: :options {<Block title>}
,#+begin_block
,#+begin_src python
import os
,#+end_src
,#+end_block
#+end_src

* Speaker notes
Exports to =\note{}= and does not show on the slide.

#+begin_src org
,*** Notes :B_note:
:PROPERTIES:
:BEAMER_env: note
:END:
- <what to say>
#+end_src

* Bibliography
Last heading of the file. Add `:BEAMER_opt: allowframebreaks` to the
References frame only when the list runs past one page. On one page it
adds a roman numeral to the title.

#+begin_src org
,* References :B_ignoreheading:
:PROPERTIES:
:BEAMER_env: ignoreheading
:END:
,** References
,#+print_bibliography:
#+end_src
